# 《东境》村庄成长：下一阶段制作方案

日期：2026-10-22。**除下述小工坊基线外，本文均为待制作方案，不代表已经实现或完成平衡验证。**

当前已有生产、消费、服务、运输和七区开拓，但改善生活主要体现为库存与幸福度变化。下一步先让经营结果变成可见的生活与具体经历，不继续堆资源条、建筑数量和升级按钮。

小工坊已调整为2名普通劳力，满配每日消耗4木材、产出12铜钱、维护2铜钱，真实开局及三条完整流程回归已通过。新增玩法不能成为开局赚钱的唯一渠道，近期也不安排缺少自产来源的木器委托。

## 一、生活改善 → 院落成长 → 想继续经营

住宅自动记录少量生活状态，保留1×1占地、完整围栏和现有乡野色调。玩家通过已有建设、道路与供给改善生活，不必逐栋点击升级。

| 状态 | 真实触发依据 | 默认镜头下的反馈 |
| --- | --- | --- |
| 新居 | 建筑落成 | 基础围院与少量家具 |
| 安家 | 居民入住，该户真正收到并消耗口粮 | 晒架、生活篮筐、少量花草与门边小灯 |
| 街坊生活 | 已安家，获得有效公共服务，或实际吃过两种粮食来源 | 院内坐凳、小菜畦，以及相应生活片段 |

只检查该户真实消费和服务，不能因仓库有粮、附近摆着断路集市就触发。没有“稳定N日”条件，没有经验条。普通农户也能拥有完整生活布置，生活改善不等于变成匠户。

先做三种短片段：回家整理物件、去集市买菜、亭边休息。复用已有居民、合法路径和站位；NPC仍为表现层，走路匀速、过河走桥，不影响经济结算。目的地不可达就取消片段，不瞬移。设同屏活动上限，不按每栋住宅无限增加角色。

解锁的院落布置保留，当前缺粮与断路仍显示真实异常；空屋不刷人群。组件根据住宅ID固定选样，刷新和读档不随机换样。摆件留在原占地内，不遮入口、道路和屋顶识别件，不产生免费税收或岗位。

**验收：**正常新局无需点击住宅即可看到首次安家；空屋、断路服务不误触发；同机位前后画面可辨认变化；倍速、断桥、删目的地不使NPC加速或穿河；重复刷新和存读不叠加摆件。

## 二、经营余量 → 一件乡事 → 留下具体成果

“经营”中提供最多两个乡事提议，玩家主动接一个。接受前显示需求、现金与场景成果，接受后主界面只留一行，例如“邻村备粮：还需交付6粮食”。目标不刷新加码，无倒计时、无失败罚款，完成不自动续单。

| 第一批内容 | 交付与现金回报测试初值 | 首次完成留下什么 |
| --- | --- | --- |
| 邻村备粮，故地有余粮后出现 | 8粮食 → 10铜钱 | 来客致谢片段、村口乡邻布幡 |
| 赶集新衣，布衣开放后出现 | 4布衣 → 10铜钱 | 挑选衣物片段、晒布装饰组合 |
| 春茶捎信，茶叶开放后出现 | 6茶叶 → 14铜钱 | 来客饮茶片段、茶席组合 |

上述数值仅供测试，未验证平衡。近期先完整做第一条，不先生成几十种换数字的任务。故地商路4单位/日时，8粮食理想交付约2模拟日；这是履约估计，不是等待型目标。

交付复用库存、商路与配送预算。居民口粮、加工必需原料优先；乡事与普通卖单在剩余额度中轮转，不重复扣货、不另送免费运力，也不能覆盖玩家原有买卖订单。每个实际成交单位按标准卖价到账，完成后再发一次尾款；以上三个初值的尾款均为2铜钱。取消保留已成交结果，未交付库存不扣、不发尾款。任务ID防止重复领取。

只给已经开放、具备现实获取方式和可用商路的提议。可通过生产或进口筹货，但总回报应低于直接进口成本，避免循环套利。首次装饰仅解锁一次，重复完成不叠加永久经济加成。

来客与装饰自动出现，不需要领奖。暂时没有合法站位时先记录成果，之后再表现，不阻塞交付。完成后下一件事静静留在经营入口，不连环弹窗。

**验收：**真人从新局完成“看到提议→接取→交付→收钱→看见来客与纪念物”；争取前10分钟有机会完成首单，若商路阻塞则调小货量，不取消口粮保护；断路、缺货准确提示并恢复；取消、读档不重复钱货；普通卖单与乡事并存均能推进；完全忽略乡事仍可通关。

## 三、新区开放 → 生活选择 → 不同的村庄

前两环稳定后，再在新区提供一次可跳过的生活方向选择：

| 方向 | 后续机会 | 可见变化 |
| --- | --- | --- |
| 热闹乡集 | 更常出现已开放粮食、布衣等集会筹备委托 | 布幡、摊边来客、集市交流 |
| 水岸闲居 | 更常出现已开放茶叶、纸张等生活筹备委托 | 水边坐凳、茶席、读书休憩 |

改变提议和装饰组合，不加声望、专属货币、隐藏产量倍增，也不锁产业。下一次开拓可免费改选；未开放商品不能提前派单，没有合法岸边站位时使用院内替代点。若现有片段无法体现区别，先扩充前两环，不急着上线一个空称号。

**验收：**相近人口、资源和建筑规模下，两个方向的任务和默认镜头生活画面有明显区别；玩家无需逐栋重配；原有五项开拓条件不变。

接入以现有家庭消费／服务记录、订单与地区预算、NPC路径、住宅外观组件为基础。逻辑只保存家庭生活状态、任务进度、已领取ID和装饰权限；画面刷新不能反向发奖励。测试使用隔离夹具，不碰玩家存档。

第一阶段交付证据应包含同机位新居／安家／公共生活对比、首单完整操作录像、交付账本，以及不做乡事的主线回归。再通过真人试玩观察玩家是否看懂变化、是否主动想做下一件事；脚本通关不能单独证明这一点。

保持原有资源目标，不恢复建筑数量或稳定天数要求，不增加常驻进度条、逐栋供给开关与每日红点。四季、人物故事可后续围绕上述生活事件扩展；灾害、疾病扩散、科技树、更多材料链暂缓，先让已有经营成果值得欣赏。
