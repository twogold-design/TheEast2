## 2. 本次直接改变的体验

- **人口迁入改为每30模拟秒最多2人。** 冷却达到30秒后会保留资格，条件恢复时立即尝试迁入，不再失败后重等两分钟。只有一个空床时也能迁入1人。
- 条件为有接路的空床位、幸福度至少55、粮食至少为人口加2。已删除“上一检查周期粮食净增长不能为负”的门槛。顶部人口提示显示当前阻碍。
- 常规库存、价格、维护、产出、费用及状态数量不显示小数。小于1而尚未归零的数量可显示“不足1”；内部仍累积定点余量，避免每步取整吞掉收益。UI的整数不是把生产改为按整天瞬间结算。
- 底栏建筑tips只保留“产出”和“消耗”，劳力与维护并入“消耗”。
- 农户提供普通劳力，匠户提供工匠劳力；住宅自身不占劳力，也不生产货物。故地即可将住满4人、接路且幸福度至少55的住宅改建为匠户，无需先开拓北坡。
- 改建支付**木材12、铜钱8，工期1日**，不再要求购买木器、布衣或保留“1分钟缓冲”。1日等于60模拟秒；暂停会停工，倍速会加快。断路也暂停工期，原居民保留住房。
- 完工后，原有4名普通居民变为4名工匠，不增加人口。**1名居民对应1份劳力**；普通与工匠是独立池，不互相补位，也不再按人口的70%折算。工匠必须到对应加工建筑工作，家里不会扣木材或产木器。
- 取消住宅“供应木器/布衣”选择控件。匠户自动使用可获得的布衣与陶器，缺货影响消费收益和幸福，不立即把住宅降回农户。
- 建筑详情只保留住宅升级等必要操作。**取消配方切换、用工优先级、单栋停产／启用按钮**，建好的建筑按固定用途自动运行；全局时间暂停与倍速仍保留。缺工通过合理安排普通居民、工匠和建设数量解决。
- 粮田固定产粮；北坡新增独立**麻田2×2**，固定产麻。小工坊使用**2名普通劳力**，每日消耗木材4、获得铜钱12，另付维护2，满配自身净收入10铜钱/日；不生产木器，不需要匠户或手动卖货才能赚钱。缺木、缺工、断路时加工收入停止，维护仍需支付。

## 4. 商品、生产与铜钱

十一种货物字段为饮水、粮食、木材、麻料、木器、布衣、茶叶、黏土、陶器、竹材、纸张。木器目前仅保留买卖和库存，不再由小工坊生产，也不是居民必需品；其余十种有生产或消费用途。顶栏显示人口、木材、水、粮食、衣物、铜钱、幸福度；悬停衣物显示“相关物料：麻 100”和“麻田产麻 → 织坊制衣”；中间原料在对应建筑详情中说明，章节目标仍沿用五项参数。

内部净变化统计使用最近1日的滚动收支；货物统计包含在途量，跨区发车和抵达不会被误计为消耗或生产。顶部可用库存排除在途和断路地区的货物。

居民提供基础公共收入，初期农林经营可持续运转。小工坊把实际消耗的木材直接结算为铜钱，提供明确的开局增收渠道；不经过市场订单，不占商品外贸额度。额外收入还来自实际居民消费和茶馆消耗茶叶；集市、道路、仓库、书院不直接固定印钱。建筑即便缺工或断路仍有维护支出。建造前要保留岗位和经营余额；过度建设可拆除调整，不再靠反复开关建筑分配劳力。

当前不开放买卖面板。建设和生活物资由本地生产、沿路网自动配送；铜钱来自居民税收、实际生活消费和小工坊加工。

## 5. 地区库存与运输

每个地区拥有自己的货物库存与仓容，无配送额度。本区生产优先入本区库存，居民与加工消耗本区可用货物；另一区有货不代表当前工坊可以瞬间使用。

经营面板、买卖订单及手动专线入口已撤下。读取旧档时停止其尚未完成的买卖及手动路线，清除自动贸易策略；已经在途的本镇货物继续送达，按真实路网自动补货仍有效。

缺货地区根据居民、加工与服务需求自动申请调拨，寻找有余量且存在合法道路或码头水路的来源。货物发出时扣除源区库存，形成在途记录，经过与道路／航道距离有关的时间后才入目的库存。断路会暂停并保留在途货物；接通可恢复，目的区没有库位则等待卸货。更换可用路径会调整余下行程。

运输使用逻辑货包，NPC、动物和观光船仍独立表演，不会因渲染卡顿多生产、吞货或加速经济。

玩家通过源区生产、目的区消费及道路连接组织供给链，无须逐条开通专线。已取消地区运力额度、本地装卸预算及单批货量限制。建多个产业不会因为隐藏运输指标而减产；真实缺工、原料短缺、断路和仓满仍影响生产。

| 建筑 | 当前作用 |
| --- | --- |
| 仓库 | 接路即生效，无需工人，每种货物仓容增加基础上限的50%（木50、水25、粮50、衣30，其他各100）；多座容量叠加 |
| 粮仓 | 额外粮食仓容800 |
| 货运站 | 接路且配齐2名普通工人时，本区发出的道路货物运送时间减半；同区不叠加 |

## 6. 居民服务与幸福

幸福来自真正获得的饮水、食物和衣物消费、道路可达的服务和食物来源多样性。医馆、集市、亭园、文化和茶馆各有服务范围与容量，住宅距离过远或人数超过覆盖能力就不能获得完整收益。

- 医馆提供医疗；书院和戏台属于同一文化类别，对同户取有效较高值，不能逐栋叠加。
- 书院有基础服务能力；实际消耗纸张可以提高服务容量，缺纸不会抹掉基础文化作用。
- 茶馆实际消耗茶叶，供给量影响休闲服务并产生消费收入。
- 休憩亭根据周边实际景观发挥作用；园林提供人工公共空间基础，附近景观进一步改善效果，两者同属园景类别。
- 田粮、鱼塘、果园、进口保留粮食来源。最近1日实际消费中至少两种来源各占25%，才能得到完整多样性加成；造两座同类农田不算两种来源。这个窗口不是章节等待条件。

农户每天每人消耗水0.5、粮食0.5；匠户每天每人水1、粮食1。北坡开放后普通农户每人每日消费衣物0.125，匠户衣物0.25及陶器0.125。四位农户每日需水2、粮2，每两日需衣物1；衣物与陶器实际消费增加幸福和收入。短期缺衣不阻断劳作；按户缺口累计1日暂停迁入，从累计2日起全城每2日最多因缺衣离开1人，部分供给按缺口比例延缓累计，足供清零。缺衣不保留最后一名普通居民或工匠。缺水、缺粮或幸福度低于40时，每持续1日结算一次减员：缺粮离开2人，否则离开1人；这些条件同时发生不叠加人数，也不与缺衣重复扣人。连续缺水30模拟秒阻碍迁入；恢复供给且幸福度达到40后解除相应压力。1日为60模拟秒，暂停停止计时，倍速按模拟时间推进。

住宅升级把普通人口转为工匠人口，同时让水粮需求翻倍、提高衣物需求并新增陶器需求。匠户民居是两层小楼，保留1×1院落，增加二楼阳台、木栏杆和窗棂。改建时房屋上方小锤子循环敲打，暂停或断路时停锤；完工时伴随一次短暂扬尘切换为小楼，读档不重复播放。织坊、陶窑、造纸坊需要工匠；小工坊、粮田、麻田、伐木场、物流和其他服务使用普通劳力。两个池不互相代班，应按岗位数量逐户升级，保留足够普通人口维持口粮、加工收入和运输。住宅用“匠”牌和工具挂架区分阶层，没有加工台或成品堆。

## 7. 推荐的试玩检查顺序

1. 故地先接路建设粮田、伐木场和水井，追加可入住民居，观察30秒迁入及具体阻碍提示。有可用普通劳力和木材后建小工坊，确认铜钱净变化转为正增长；不必先升级住宅。用全局暂停规划布局，用工不足时补接路住房并等待迁入，避免继续过建。
2. 开拓北坡后，建设麻田与织坊供应衣物；改建一栋匠宅，观察工期、完工标识和工匠岗位变化。织坊需要工匠，小工坊仍需要普通劳力，不要把全镇居民都改为工匠。
3. 向东麓扩张，把一种原料安排在新区，另一地区使用它，观察在途和抵达；区分仓满、原料不足和道路中断的解决办法。
4. 到高台、东原后，把医疗、园景、文化安排在住宅可达范围内；选择茶业、纸业自产服务原料，比较土地和维护成本。
5. 北关提供泥陶产业和水路选择；新都提供更高贸易处理能力。继续围绕五项公开数值完成开拓和最终目标，而非建齐26栋。

这是玩法观察顺序，不是已经验证的最短或必胜路线。真实付费通关、不同布局与不同经营路线需要分别记录证据。

## 8. 目标、失败与结束后继续

每阶段目标由木材、粮食、铜钱、人口、幸福度构成，不使用建筑数量、固定组合、匠户人数或稳定天数。目标达成逐项标绿，费用与奖励留在开拓操作时提示。

人口或实际铜钱归零立即失败，显示原因并暂停游戏，仅提供重新开始。缺水、缺粮、缺衣及幸福度低于40可持续造成居民离开，直到人口为0；最后一名居民离开后，不能被同一结算中的迁入抵消。幸福度恰好40不触发低幸福度减员；内部仍为正的不足1铜钱不视为破产。木材、麻料、竹材等建造或生产原料短缺通过停产间接影响生活供应，不因未使用的原料库存为0直接扣人。

开放全部七区后还要达到最终五项要求，才触发“东境全域复兴”。胜利弹窗可以选择**继续经营**，解除暂停并保留成就状态，避免反复弹胜利窗；也可以重新开始。继续经营后仍保留经济约束与失败条件。

## 建筑收支显示口径

建筑卡牌与详情按每日净值显示资源：同一资源先合计全部产出，再扣除原料、燃料和维护中的同类消耗；正数归产出，负数归消耗，抵消为零则不显示。小工坊显示铜钱10/日、消耗木材4/日；茶馆显示铜钱4/日（满客）、消耗茶叶2/日。劳力、服务和仓储效果单列，书院纸张仍为可选项。此项只合并说明，实际生产、消费和维护结算规则保持不变。
