## 3. 敏感性与产业链中断

需求±10%采用固定配置的算术敏感性分析，未把它描述为额外两次全流程实机测试。需求增加10%时，16人配置水缺1/日，32人配置水粮各缺2/日，48人配置衣物缺1.6/日。扩人口与升级前必须检查余量；小幅变化会产生扩产压力。

16人城镇的断麻试验使用真实引擎：起始16麻、24衣，拆掉麻田，剩余原料仍可加工，之后织坊因缺麻停产。首次人口流失发生于第10日，持续不补给最终人口归零并失败。库存缓冲解释了“拆掉原料建筑后成品没有马上停止”的现象，不能把这种正常消耗库存误判为无限生产。

## 4. 从新局到胜利：真实付费路线

起点为4人、木100、粮40、水40、衣12，初始民居扣款后钱56。建筑、道路、匠户升级、开拓全部使用正式扣款与放置逻辑；没有资源赠送、人口注入、手动交易或跳章节。测试脚本先只读规划地形通道，再按已解锁范围实际建路，避免自己的布局堵死出口。

该路线没有建齐所有可选建筑；陶纸完整配置的持续经营由上一节另行验证。测试中的建筑模型用轻量占位对象降低模拟开销，地图地形、道路连通、占地、经济与Main胜利判断使用正式逻辑，模型画面另行渲染检查。

两个布局约束已记录：必须预留道路出口；木材仓容按地区计算。产木地区只有一仓时上限150，低于最终木目标160；本路线在同一产区建第二仓后通过，未降低目标绕过问题。
