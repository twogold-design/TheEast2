## 材料顺序

- 水井 → 麻田 → 织坊 → 集市、医馆、戏台；基础住房可改建为匠户，为织坊提供工匠。
- 水井 → 竹林场 → 果园、货运站、亭台、茶园、粮仓、采泥场等。
- 竹林场和麻田 → 造纸坊 → 书院。
- 采泥场 → 陶窑 → 商栈。
- 茶园 → 茶馆。

建筑使用的材料均有本阶段或此前开放的可重复生产来源，不依赖初始库存才能启动。基础农田、水井和伐木场不要求它们自身的产物以外的新材料；衣物耗尽时也可以重新建立麻田、织坊链。

## 界面与结算

建筑卡牌分两行显示材料费用；详情的“建造”行显示一次性成本，“产出／消耗”显示每日经营量。建造检查所有材料并一次性扣除，任何材料不足都不扣其他费用。拆除返还各项建造资源的一半，取整向下；退款提示列出全部资源。

## 验证边界

`qa/ConstructionMaterialsAcceptance.gd` 使用隔离游戏实例，覆盖全部26种建筑的实际付费放置、20种建筑新增材料的逐项短缺与过期预览、原子扣款、退款和文字一致性。按七个开放阶段检查材料依赖闭包，确保无循环及跨越尚未开放阶段的材料门槛。使用1366×768实际渲染检查多材料卡牌与切页位置，截图位于 `qa/construction-materials/`。

依赖检查证明材料链可建立，不代表已经重新跑完七区通关或完成长期经济平衡测试。此前通关报告继续作为历史基线。
