# 江南水墨建筑资源 v3

v3 用完整合理的江南坡屋顶、屋脊、飞檐和前廊替代 v2 的单层屋檐。建筑保留可见的天井、院墙、门楼、梁柱、窗格、招牌、货物和生产工具，让高位镜头既能读出建筑功能，又不会看到被整片屋顶覆盖的黑块。

## 资源

- `models/`：住宅、农舍、伐木场、仓库、工坊、集市、茶亭 7 个 GLB。
- `source/jiangnan_style_v3_gallery.blend`：可编辑 Blender 源文件。
- `previews/jiangnan_style_v3_gallery.png`：资源总览。
- `models/jiangnan_style_v3_manifest.json`：尺寸、入口方向和功能可读性清单。
- 生成脚本：`tools/generate_jiangnan_style_assets_v3.py`。

v2 和 `realistic` 资源保持不变，缺少 v3 文件时由 Godot 注册器回退。
