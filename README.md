# 东境：孤城新生

一个使用 Godot 4.7.2 制作的原创东方古代河谷城镇 3D 模拟经营原型。玩家通过九类住宅、生产、商贸和公共建筑维持资源与民心，并沿七章目标链逐级开拓 48×48 的东方河谷。主场景恢复使用第一版写实资源，居民会按日程在住所、岗位、仓库和河湾步道之间活动。

## 编辑器启动

最方便的方式是双击项目根目录的 `启动游戏.bat`。默认直接进入游戏；需要打开编辑器时运行：

```powershell
& 'M:\NewGames\TheEast\启动游戏.bat' editor
```

当 `project.godot` 已建立后，在 PowerShell 中运行。先把 Godot 的编辑器配置、日志和临时目录重定向到项目内，避免默认写入 C 盘：

```powershell
powershell -ExecutionPolicy Bypass -File 'M:\NewGames\TheEast\run_editor.ps1'
```

直接试玩可运行：

```powershell
powershell -ExecutionPolicy Bypass -File 'M:\NewGames\TheEast\run_game.ps1'
```

启动脚本会自动完成下面这些环境变量设置；需要手动启动时使用：

```powershell
$godotData = 'M:\NewGames\TheEast\.godot-user'
New-Item -ItemType Directory -Force "$godotData\Roaming", "$godotData\Local", "$godotData\Temp", "$godotData\Logs" | Out-Null
$env:APPDATA = "$godotData\Roaming"
$env:LOCALAPPDATA = "$godotData\Local"
$env:TEMP = "$godotData\Temp"
$env:TMP = "$godotData\Temp"
& 'D:\tools\Godot-4.7.2\Godot_v4.7.2-stable_win64.exe' --editor --path 'M:\NewGames\TheEast' --log-file "$godotData\Logs\editor.log"
```

在编辑器中按 `F6` 运行当前场景，按 `F5` 运行项目主场景。

也可以直接双击根目录的 `启动游戏.bat`。该脚本会清理项目路径末尾的反斜杠，再传给 Godot，避免 Windows 将结束引号和后续参数误解析成项目路径的一部分。

启动器支持以下检查命令：

```powershell
cmd.exe /d /c call "M:\NewGames\TheEast\启动游戏.bat" check
cmd.exe /d /c call "M:\NewGames\TheEast\启动游戏.bat" test
cmd.exe /d /c call "M:\NewGames\TheEast\启动游戏.bat" render-test
```

`check` 检查引擎和 `project.godot` 路径；`test` 无窗口加载主场景，并自动验收中键平移、自动时间、暂停/倍速、目标栏折叠，以及区域建筑的解锁、分页菜单、道路连通、运输收益、每日效果和 v4 存档；`render-test` 短时启动实际图形渲染。日志写入 `M:\NewGames\TheEast\.godot-user\Logs`。

## 操作

- 左键单击：建造、铺路或查看物件
- 按住鼠标中键拖动：平移地图
- 右键短按：取消当前建筑或道路摆放
- 右键拖动：旋转与调整俯角
- 鼠标滚轮：缩放
- 选择底部建筑后点击格子：建造
- 摆放建筑时按 `R`：每次旋转 90°，预览与占地同步改变；中键保持拖动地图
- 点击底部独立的“铺路”按钮后再点击可铺设格子：逐格铺设，每格消耗 1 木材
- 再次点击当前建筑按钮，或按 `Esc`：取消摆放并回到查看模式
- 左键点击已有建筑：选中并打开详情，可暂停/启用生产，或用“删除建筑”拆除并返还一半木材与铜钱
- 左键点击玩家铺设的道路：查看其主路连通状态，并可拆除
- 时间默认自动以 1× 流逝，每 8 秒结算一天；底栏可暂停或切换 1×/2×/4×
- 右侧目标栏右上角的箭头可收起/展开，收起后顶栏仍显示当前任务
- 顶栏“设置”：调整背景音乐音量或静音，并展开查看模式、保存进度、读取存档和重新开始；这些低频操作不再占用底部建造栏
- 读取与重新开始会先要求确认；启动时仍会自动续读有效存档
- 存档在编辑器中写入项目内 `saves`，导出后写入可执行文件旁的 `saves`

新局拥有 60 铜钱。建筑费用为：民居 12 木/4 钱、农田 18 木/6 钱、伐木场 22 木/6 钱、仓库 30 木/10 钱、小工坊 38 木/16 钱；这五类全部从开局可用，并集中显示在“基础”页。北坡开拓后，“产业”页同时解锁集市（45 木/18 钱）与鱼塘（40 木/16 钱）；高台、东原随后分别解锁医馆（52 木/24 钱）与书院（68 木/38 钱），图鉴共九类。后续建筑按“产业 / 民生”分页，锁定项直接标出开放区域。

鱼塘提供 2 个岗位，在岗 0/1/2 人时每日分别产出 0/7/14 粮食，启用期间维护费为 2 铜钱/日；暂停后停止生产、释放岗位且不收维护费。满员运行并接通村庄主路时，鱼塘获得 1 铜钱/日运输收入，计入全城每日 6 铜钱上限。鱼塘不参与农田和伐木场的民生交易收入。

道路属于独立基础设施，不计入开局五类建筑，也不计入章节要求的建筑数量。玩家可从底栏独立的“铺路”入口按 1 木材/格逐格铺设；道路通过上下左右相邻接入村中主路后生效，桥梁可连接两岸路网。已解锁林区的空格允许铺路，有实际树木的格子必须绕行，预览和铺路均不会移除树木；居民也会避让树格。地图内部石头格允许铺路，道路占格时清除石头显示，取消预览或拆路后恢复，外围装饰不受影响。首区可沿林间空隙连通相邻地块。锁定区域、外围缓冲区、水面和建筑占格不能铺路。与已连通道路相邻、且当天正常运行的农田、鱼塘、伐木场、小工坊、集市和书院，每座提供 1 铜钱道路运输收入，全城每日最多 6 铜钱。断路不停止原有生产；道路可以选中拆除。

旧存档已经清树的道路保持可用，迁移后记录专用历史标记；拆掉该历史道路后树木恢复且不可重新铺设。新存档写入 `road_rules_version=2`，树格道路缺少有效历史标记时拒绝读取，避免一般读档绕过铺路规则。

系统把人口的 70% 向上取整为有效劳动力，按农田 → 鱼塘 → 伐木场 → 小工坊 → 集市 → 医馆 → 书院分配。农田、鱼塘与伐木场按实际在岗比例生产；小工坊必须 3 人满员，并整份消耗 4 木材与 2 粮食后获得 10 铜钱；集市满员消耗 3 粮食获得 9 铜钱；医馆满员使幸福目标 +7；书院满员每日增加 5 铜钱并使幸福目标 +4。玩家可暂停单座生产或公共建筑，重新分配劳动力。暂停建筑上方显示“Ⅱ”，缺工、当前配方缺原料或仓库未接通主路时显示“!”；选中建筑可查看具体原因，恢复运行条件后标记自动隐藏。部分在岗仍生产的农田、鱼塘、伐木场及住宅不显示停产标记，正常接通主路的仓库也隐藏警示。

每日口粮为人口的一半向上取整，且每座民居额外消耗 1 粮食。每日人口税为人口的一半向下取整，至少获得 1 铜钱；有工人运转的农田和伐木场还会参与民生交易，每处获得 2 铜钱、每日最多 4 铜钱。小工坊的 10 铜钱加工收入提供更高的增收效率。农田、伐木场、仓库每天各需 1 铜钱维护，小工坊、集市和鱼塘需 2 铜钱，医馆需 3 铜钱，书院需 4 铜钱；欠款会中断稳定经营与居民迁入。仓库边界相邻的道路接通村庄主路后，木材和粮食容量才各增加 75；仅贴着一段孤立道路不生效，仓库本身不获得运输收入。

仓库未连路时显示红色“仓储停用”和头顶警示，接通后立即恢复绿色状态；维护费仍固定收取。新四格仓院的各边及旧一格仓库均支持接路。断路或拆仓造成容量下降时，已有库存和拆除返还不被删除；超容量期间停止新增入库，正常消耗不受影响，重新接通后继续入库。超容量存量可正常保存读取。

人口或铜钱降至 0 时立即失败。每日幸福度完成全部结算后，低于 40 会离开 1 人，低于 20 会离开 2 人；若当天同时缺粮，只采用缺粮与低幸福流失人数中的较大值，不重复相加。幸福度连续三日低于 20 的原失败条件仍然保留。七区全部开放后，还需人口 45、木材 200、粮食 200、铜钱 150、幸福度 80，才能完成“东境全域复兴”。

存档当前写为 v4，并在 v3 的铜钱、稳定天数、维护欠款及建筑启停状态之外包含必需的 `roads` 道路坐标数组。新存档记录失败原因 `failure_reason`、建筑旋转 `rotation_quarters`（整数 `0`～`3`，每级 90°）、仓库占地 `warehouse_footprint`（`1` 或 `2`）和农田占地 `farm_footprint`（整数 `1`、`2`、`4`，分别表示基础尺寸 1×1、2×1、2×2）。这些字段均可省略：旧档角度默认 0，原仓库与农田保持 1×1，失败原因默认空文本。农田字段记录基础占地面积，加载时再应用旋转，旧两格农田不会扩大或缩成一格。v1 存档按河湾故地读取，v2 保留原区域等级，v3 保留全部既有经营状态；v1～v3 缺少道路字段时按空路网读取，下一次保存时统一迁移为 v4。

当前大地图与目标链规格详见 [`MAP_GOALS_DESIGN.md`](M:/NewGames/TheEast/MAP_GOALS_DESIGN.md)。

工坊与医馆新增可选占地字段 `workshop_footprint`、`clinic_footprint`，均只接受整数 `1` 或 `2`，分别表示原版 1×1 与新版 2×2。旧文件缺少字段时按一格读取，保留旁边建筑和道路；新建建筑默认四格，保存、旋转和读档均保留明确尺寸。旧紧凑模型及人物不整体缩放，生产、岗位、维护费和解锁条件不因占地扩大改变。
